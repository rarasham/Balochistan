# PakOlivita — Editable Website

## How to edit
- Open `index.html` in a browser to view the website.
- Open `index.html` in VS Code / Notepad++ / Notepad to edit text, sections, colors and links.
- Put new photos in `assets/` and change the image filename in `index.html`.
- To add another page, copy `index.html` to a new file such as `about.html`, then add a navigation link.

## Main files
- `index.html` — complete website
- `assets/olive-garden-1.jpg` — farm photo
- `assets/olive-garden-2.jpg` — farm photo
- `assets/olive-garden-3.jpg` — farm photo

## Publish online
Upload the whole folder to Netlify (drag-and-drop) or upload it to GitHub Pages.

Important: keep the `assets` folder beside `index.html`; otherwise the photos will not appear.
